# Syntra 

Syntra is a full-stack social networking platform for college students focused on meaningful connections through profile discovery, mutual crush matching, real-time messaging, and content sharing.

## Features

* User Authentication (JWT + Cookies)
* Profile Creation & Discovery
* Crush & Match System
* Real-Time Messaging with Socket.io
* Social Feed (Images & Videos)
* Likes & Comments
* Activity Center
* User Search

## Tech Stack

**Frontend**

* React
* TypeScript
* Tailwind CSS
* Framer Motion

**Backend**

* Node.js
* Express.js
* MongoDB
* Mongoose
* Socket.io
* JWT Authentication

## Core Flow

```text
Discover Profiles
      ↓
Send Crush
      ↓
Match
      ↓
Chat
      ↓
Build Connections
```

## Local Setup

```bash
git clone <repo-url>

cd backend
npm install
npm run dev

cd ../frontend
npm install
npm run dev
```
